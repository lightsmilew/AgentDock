# 使用指南

## 启动与工作范围

运行 `AgentDock.exe`，源码目录也可使用 `Start-AgentDock.cmd`。默认数据目录为 `%LOCALAPPDATA%\AgentDock`，包括数据库、工具库副本、生成草稿、配置备份与启动档案。

```powershell
.\AgentDock.exe --data-dir "D:\AgentDockData"
```

同一数据目录只允许一个实例，再次启动会唤醒已有窗口。独立数据目录可隔离管理器数据，但不会隔离本机 Agent 安装与原生配置；测试安装卸载须另设项目内专用目标。

在设置页选择项目目录。用户级部署面向当前 Windows 用户，项目级部署使用该项目的对应 Skill 目录。实际目标在部署前确认，不以管理器 EXE 目录作为项目目录。

## Skill 工具库

1. 扫描已有 Skill，或导入包含 `SKILL.md` 及其支持文件的目录。
2. 使用搜索、分类和收藏定位条目，星标实心表示已收藏。
3. 外部 Skill 可以直接部署。需要编辑源内容时，先导入为工具库副本；导入与部署用途不同。
4. 选择 Agent 和用户级 / 项目级范围，检查目标与冲突提示后部署。
5. 在部署记录查看目标，或暂停、恢复指定副本。原文件已在目标目录时不会重复复制或接管为副本。

编辑保存后可查看历史版本。ZIP 导出用于迁移完整 Skill 或通过原工具导入。WorkBuddy 使用官方技能页面导入 ZIP，不能套用 CodeBuddy CLI 的目录。

长正文可以滚轮滚动或拖动滚动条；列表与正文滚动分别作用于鼠标所在区域。

## 模型服务

选择服务商预设，填写实际 API 地址、认证方式与凭据。一个连接可保存多个模型 ID，并指定默认模型；表格底部加号增加行，也可使用服务支持的模型列表接口获取 ID。

| 协议 | 用途 |
|---|---|
| OpenAI Chat Completions | 使用 `/chat/completions` 的兼容服务 |
| OpenAI Responses | 使用 `/responses` 的服务 |
| Anthropic Messages | 使用 `/messages` 的服务 |

服务商名称不代表其所有端点都支持三种协议。模型 ID 必须使用账号可调用的真实 ID；预设不承诺模型权限。Azure 还需按实际资源配置部署名、API 版本与地址。

“聚合”指 OpenRouter、硅基流动等统一转发多家模型的服务；“本地”指 Ollama、LM Studio、vLLM 等服务端点。添加连接不会安装这些服务或自动下载模型。

连接测试会向所选服务发送请求，可能产生调用费用。模型列表接口成功也不保证某个模型能够实际生成内容。

## Agent 管理

展开一项 Agent 即可查看桌面程序、CLI、配置来源和当前配置模型。操作顺序如下：

1. 检查安装状态；需要时使用“定位程序”，或从“重新检测”进行后台磁盘搜索。
2. 在模型服务中创建兼容连接及模型列表。
3. 回到 Agent 展开区域选择连接和默认模型，预览将修改的文件与生效方式。
4. 确认后应用。原文件会备份，设置页可恢复已记录的配置备份。

原生配置、启动档案和账号模型的作用范围不同，详见 [适配范围](adapters.md)。会话参数、项目配置、企业策略和账号权限可能覆盖默认项。

安装按钮统一显示“安装”。同时提供桌面版和 CLI 时先选择版本；支持自定义目录的桌面安装显示路径设置，CLI 使用官方目录。Codex 与 Claude 的 MSIX 桌面安装位置由 Windows 管理。安装中按钮变为“取消”；取消中断本次进程组，但不撤销安装器已完成的系统更改。

卸载使用已核实的安装来源。“彻底清理用户数据”默认不勾选；勾选并核对范围后才清理对应配置、认证、历史、缓存与 Skill。项目和其他工具共享数据不作为默认卸载目标。

## Skill 生成器

选择连接，输入目标、使用场景和预期结果后生成。更多选项可补充语言、深度与背景约束。生成过程中可从预览区域中断请求；生成后可编辑、质量检查、完善当前草稿、恢复上一版，再保存到工具库。

质量检查发现结构与描述问题，不能代替实际任务验证。草稿按设置保存；只有生成或完善时才发送给所选模型服务。

## 数据与快捷键

管理器保存的 API Key 使用当前 Windows 用户 DPAPI 加密。部分 Agent 原生文件要求明文凭据，预览会提示；从管理器启动时注入的环境变量只对该进程及其子进程生效。

备份整个数据目录前应退出程序，或使用一致的数据库备份方式；运行中的数据库还可能存在 WAL 文件。配置备份仅对应已记录的 Agent 文件，不代表完整系统或全部会话备份。更换 Windows 用户后，原 DPAPI 密文通常无法直接解密，应重新填写凭据。

| 快捷键 | 操作 |
|---|---|
| `Ctrl+K` | 聚焦顶部全局搜索 |
| `Ctrl+F` | 聚焦当前页搜索 |
| `Ctrl+1` 至 `Ctrl+6` | 切换主页面 |
| `F5` | 刷新 |

搜索在本地按名称、标题和描述等匹配，不调用 LLM，也不提供向量语义检索。
