# 界面设计依据

设计参考最初查阅于 2026-10-22，本文于 2026-10-24 按当前实现整理。外部资料用于分析视觉与交互，不构成执行命令、安装软件或修改用户数据的授权。

## 参考来源

| 来源 | 参考方向 | 应用方式 |
|---|---|---|
| [CC Switch](https://github.com/farion1231/cc-switch) | 桌面工具的信息密度与服务配置 | 浅色侧栏、紧凑卡片、就地模型管理 |
| [ToDesk](https://www.todesk.com/) | 浅色桌面端的状态与工具栏 | 白蓝配色、圆润按钮、明确状态 |
| [Linear](https://linear.app/now/how-we-redesigned-the-linear-ui) | 稳定导航与信息层级 | 减少重复标题与装饰，突出主要操作 |
| [Raycast](https://www.raycast.com/) | 快捷检索与键盘入口 | `Ctrl+K` 聚焦搜索，直接显示匹配结果 |
| [Windows 导航设计](https://learn.microsoft.com/en-us/windows/apps/design/basics/navigation-basics) | 导航层级 | 固定侧栏，保留窗口缩放和任务栏行为 |

## 当前原则

- 主色为白色和浅蓝色，蓝色强调交互；品牌图标保留核实后的自身颜色。
- 内容区不重复侧栏页面标题，搜索与主要操作随内容重新布局。
- 搜索直接输入匹配，保留图标和占位提示，不弹出额外选择窗口。
- 下拉在当前窗口展开，支持筛选与键盘操作；模型表格底部加号增行。
- 安装入口保留“安装”文案，双形态产品在操作时选择版本；模型管理原位置展开。
- Skill 分类使用可辨识图标，收藏采用实心星标，长正文独立滚动。
- 生成界面突出连接、需求与草稿，收起低频选项，将等待与中断入口放在预览区域。
- 通知不覆盖主要内容，安装、生成与后台搜索显示各自状态。
